# TDGP3D

TDGP3D is a research project on **trans-dimensional Bayesian inversion of
three-dimensional magnetotelluric (MT) data using Gaussian processes**. The
corresponding manuscript has been submitted to *Geophysical Research Letters*.

## Repository status

This repository currently contains the project description only. It does not
yet include the inversion implementation, example data, or scripts to reproduce
the manuscript results. Consequently, there are no installation or run
instructions at this time.

When the research software and materials are added, this README should be
updated with their requirements, usage, and instructions for reproducing the
published results.
